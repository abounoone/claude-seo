# 1C-Bitrix: Каталог стандартных модулей

*Обновлено: 2026-03-21*

Все стандартные модули находятся в `/bitrix/modules/`. Для интернет-магазина обязательные модули выделены ★.

---

## Обязательные модули ядра

| Модуль | ID | Описание |
|--------|-----|---------|
| ★ Главный модуль | `main` | Ядро: пользователи, группы, события, файлы, настройки сайта |
| ★ Информационные блоки | `iblock` | Основа всего контента: каталог, новости, страницы. Без него ничего не работает |
| ★ Торговый каталог | `catalog` | Цены, склад, товары, SKU, группы цен, скидки |
| ★ Интернет-магазин (Sale) | `sale` | Заказы, корзина, оплата, доставка, статусы |
| ★ Поиск | `search` | Индекс поиска по сайту |
| ★ Валюты | `currency` | Валюты и конвертация |
| SEO | `seo` | Sitemap.xml, robots.txt, мета-теги для инфоблоков |
| Статистика | `statistic` | Встроенная аналитика (обычно заменяют на Метрику/GA) |
| Файловый менеджер | `fileman` | Редактор файлов и шаблонов в админке |
| Почта | `mail` | Почтовые события и шаблоны писем |

---

## E-commerce экосистема

| Модуль | ID | Описание |
|--------|-----|---------|
| ★ Платёжные системы | встроен в `sale` | Яндекс.Касса, Сбер, Тинькофф, PayPal, Robokassa и др. |
| ★ Службы доставки | встроен в `sale` | Почта России, СДЭК, DHL, DPD и др. |
| ★ 1С обмен | `crm` / `sale` | CommerceML обмен товарами, ценами, остатками, заказами с 1С |
| Торговые предложения | `catalog` | SKU (варианты товара: размер, цвет, объём) |
| Рекомендации | встроен в `iblock` | "Похожие товары", "С этим товаром покупают" |

## CRM и бизнес-инструменты

| Модуль | ID | Описание |
|--------|-----|---------|
| CRM | `crm` | Сделки, контакты, компании, воронки (только в Bitrix24) |
| Задачи | `tasks` | Управление задачами (Bitrix24) |
| Календарь | `calendar` | Корпоративный календарь |
| Встречи | `meeting` | Переговорные комнаты |
| Чат и мессенджер | `im` | Корпоративные чаты (Bitrix24) |

*Примечание: CRM-модули в 1C-Bitrix Site Management ограничены или отсутствуют. Они входят в Bitrix24.*

## Где смотреть установленные модули

- **Админка:** `/bitrix/admin/module_admin.php`
- **Файловая система:** `/bitrix/modules/` (стандартные) и `/local/modules/` (кастомные)
- **Через D7 API:**
  ```php
  $modules = \Bitrix\Main\ModuleManager::getInstalledModules();
  ```

---

## Как определить версию Bitrix

```bash
# Через файл
cat /bitrix/modules/main/install/version.php

# Через PHP
echo \Bitrix\Main\ModuleManager::getVersion('main');
```

## Редакции Bitrix (ограничения по модулям)

| Редакция | Ключевые отличия |
|----------|-----------------|
| Start | Базовый сайт, нет e-commerce |
| Standard | + Инфоблоки, базовые инструменты |
| Small Business | + Магазин (sale/catalog), но ограниченный |
| Business | + Полный Sale, аналитика, маркетинг |
| Enterprise | + Кластеризация, персональная поддержка |
| **Business + 1С** | + Двусторонний обмен с 1С (CommerceML) |

Проверить редакцию: `/bitrix/admin/bitrix_license.php`
