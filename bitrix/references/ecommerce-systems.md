# 1C-Bitrix: Системы интернет-магазина (E-commerce)

*Обновлено: 2026-03-21*

---

## Архитектура e-commerce в Bitrix

```
Модуль Catalog (catalog)         ← товары, цены, остатки, скидки
    └── Инфоблок товаров         ← элементы = товары, разделы = категории
    └── Инфоблок SKU             ← торговые предложения (варианты)
    └── Таблицы b_catalog_*      ← цены, остатки, скидки

Модуль Sale (sale)               ← заказы, оплата, доставка
    └── Корзина (Fuser)          ← анонимная корзина по сессии
    └── Заказ (Order)            ← b_sale_order
    └── Оплата (Payment)         ← b_sale_order_payment
    └── Отгрузка (Shipment)      ← b_sale_order_shipment
    └── Платёжные системы        ← адаптеры (Сбер, Тинькофф, ЮKassa)
    └── Службы доставки          ← адаптеры (СДЭК, ПР, DHL)
```

## Каталог товаров

### Инфоблоки каталога

Стандартная структура для интернет-магазина:

| Инфоблок | Тип | Описание |
|----------|-----|---------|
| Товары (Products) | `catalog` | Основной инфоблок. Разделы = категории. Элементы = товары |
| Торговые предложения | `catalog_offers` | SKU (варианты товара). Привязан к основному через свойство |

```php
// Получить товары (D7)
$products = \Bitrix\Iblock\Elements\Element{IBLOCK_ID}Table::getList([
    'filter' => ['=ACTIVE' => 'Y', '=IBLOCK_SECTION_ID' => $sectionId],
    'select' => ['ID', 'NAME', 'PREVIEW_PICTURE'],
    'limit' => 20,
]);

// Получить цены товара (D7)
$prices = \Bitrix\Catalog\PriceTable::getList([
    'filter' => ['=PRODUCT_ID' => $productId, '=CATALOG_GROUP_ID' => 1],
]);

// Получить остаток (D7)
$stock = \Bitrix\Catalog\StoreProductTable::getList([
    'filter' => ['=PRODUCT_ID' => $productId],
    'select' => ['AMOUNT', 'STORE_ID'],
]);
```

### SKU (торговые предложения)

```
Товар "Кроссовки Nike Air"     ← элемент основного инфоблока
├── SKU "Размер 42, Белый"     ← элемент инфоблока предложений
├── SKU "Размер 43, Белый"
└── SKU "Размер 42, Чёрный"

Каждый SKU имеет свои: цена, остаток, изображение, артикул
```

Связь: в настройках каталога указывается ID инфоблока предложений.
В коде: `CCatalogSKU::GetProductInfo($productId)` (legacy) или через `OfferTable` (D7).

### Цены и группы цен

- Группы цен создаются в `/bitrix/admin/cat_price_list.php`
- Обычно: "Розничная" (ID=1), "Оптовая", "Закупочная"
- Цена привязана к конкретному SKU или товару
- Скидки: через модуль `sale` (акции, купоны) или напрямую через `catalog` (наценки/скидки на цены)

## Корзина и заказ

### Жизненный цикл заказа

```
1. Товар в корзине (Fuser — анонимная корзина по cookie)
        ↓
2. Оформление заказа (checkout)
        ↓
3. Создание заказа (b_sale_order, статус "Принят")
        ↓
4. Оплата (Payment — может быть несколько оплат для одного заказа)
        ↓
5. Сборка (опционально, кастомный статус)
        ↓
6. Отгрузка (Shipment — создание накладной, передача в доставку)
        ↓
7. Доставлен (финальный статус)
```

### Статусы заказа

Стандартные статусы (редактируются в `/bitrix/admin/sale_status_admin.php`):
- `N` — Принят (новый)
- `P` — Принят к обработке
- `Y` — Выполнен
- `F` — Доставлен
- `C` — Отменён

Кастомные статусы добавляются там же.

### D7 API для заказов

```php
use Bitrix\Sale;

// Создание заказа
$order = Sale\Order::create(SITE_ID, $userId);
$order->setPersonTypeId(1); // тип плательщика (физ./юр. лицо)

// Добавить товар в заказ
$basket = $order->getBasket();
$basketItem = $basket->createItem('catalog', $productId);
$basketItem->setFields([
    'QUANTITY' => 2,
    'CURRENCY' => 'RUB',
    'LID' => SITE_ID,
    'NAME' => 'Название товара',
    'PRODUCT_PRICE_ID' => $priceId,
]);

// Сохранить
$result = $order->save();

// Получить заказ
$order = Sale\Order::load($orderId);
$order->getField('STATUS_ID');

// Изменить статус
$order->setField('STATUS_ID', 'P');
$order->save();
```

## Платёжные системы

### Стандартные адаптеры (из поставки)

| Система | Описание |
|---------|---------|
| Сбербанк (Сбер Pay) | Эквайринг через API Сбера |
| ЮKassa (бывш. Яндекс.Касса) | Популярный агрегатор |
| Тинькофф Касса | Эквайринг Тинькофф |
| Robokassa | Агрегатор с множеством методов |
| PayPal | Международные платежи |
| Наличные | Оплата при получении |
| Банковский перевод | B2B оплата |

Настройка: `/bitrix/admin/sale_payment_system_admin.php`

### Структура платёжного адаптера

```
/local/php_interface/include/sale_payment/
└── vendor.handler/
    ├── handler.php       ← класс SalePaymentHandler
    ├── template.php      ← форма оплаты (redirect / iframe)
    └── result.php        ← обработка callback от платёжной системы
```

## Интеграция с 1С (CommerceML)

### Что синхронизируется

```
1С ──────→ Bitrix:
  Товары (каталог, описания, изображения)
  Цены (розничные, оптовые)
  Остатки (по складам)
  Категории (иерархия разделов)

Bitrix ──────→ 1С:
  Заказы (новые и изменённые)
  Статусы оплаты
  Данные покупателя
```

### Механизм обмена

1. 1С отправляет HTTP-запрос на `/bitrix/admin/1c_exchange.php`
2. Bitrix авторизует 1С (отдельный пользователь с правами обмена)
3. 1С загружает файл CommerceML (XML)
4. Bitrix импортирует данные через `/upload/1c_catalog/`

### Настройка

В Bitrix: `Магазин → Настройки → Интеграция с 1С`
- Пользователь для обмена (отдельный аккаунт)
- Частота обмена (по расписанию или по требованию)
- Настройки сопоставления полей

## Скидки и акции

### Через модуль Sale (рекомендован)

```
Магазин → Маркетинг → Акции
```

Типы акций:
- Скидка на заказ (% или фиксированная сумма)
- Скидка на товар (по условию)
- Купон (промо-код)
- Подарок к заказу
- Бесплатная доставка от суммы

### Через модуль Catalog

```
Каталог → Цены
```

- Наценки/скидки к базовой цене по группам покупателей
- Специальные цены для B2B
